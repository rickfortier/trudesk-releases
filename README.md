# TruDesk downloads

Installers for **TruDesk**, the [TRU-SENTIMENT](https://tru-sentiment.com) desktop app for stock and options analysis on Windows, macOS and Linux.

**Download the latest version:** see [Releases](https://github.com/rickfortier/trudesk-releases/releases/latest), or visit [tru-sentiment.com/download](https://tru-sentiment.com/download).

| Computer | File |
|---|---|
| Windows 10/11 (most PCs) | `TruDesk-Setup-<version>-x64.exe` |
| Windows on ARM | `TruDesk-Setup-<version>-arm64.exe` |
| macOS 12+ (Apple silicon and Intel) | `TruDesk-<version>-universal.dmg` |
| Linux | `TruDesk-<version>-x86_64.AppImage` or `TruDesk-<version>-amd64.deb` |

You sign in with your tru-sentiment.com account. The Free plan works.

This repository holds release files only. TruDesk's source code is not public.
Questions: support@tru-sentiment.com
